# TASK-003 — предметная модель и границы контрактов

- Статус: завершено
- Рабочая ветка: `task/003-domain-model-contracts`
- Целевая ветка: `main`

## Цель

Спроектировать минимальную предметную модель, канонические типы, происхождение значений, состояния неопределённости и малые контракты для первого локального сквозного среза без начала программной реализации.

## Включённый объём

- Идентичность источника, публикации и одного наблюдаемого снимка.
- Решение о границе между публикацией и физическим объектом недвижимости.
- Канонические типы, единицы, обязательность и сравнение полей первого среза.
- Критерии цены, площади и комнат.
- Происхождение каждого нормализованного значения и версия правила.
- Явные состояния присутствия, отсутствия, неподдерживаемого и невалидного значения.
- Контракты адаптера источника, нормализации, коллекции, поиска и выходного представления.
- Стабильные категории ошибок, пути, атомарный отказ, сортировка и JSON-детерминизм.
- Архитектурное решение и актуализация переносимой документации проекта.

## Исключённый объём

- `pyproject.toml`, `uv.lock`, зависимости и исполняемый Python-код.
- Pydantic-модели, JSON-фикстуры, тесты и CLI.
- База данных, ORM, миграции, API, HTTP, HTML и реальные площадки.
- Дедупликация и идентификация физических объектов.
- Нестандартные сигналы, ИИ, уведомления, UI, OpenClaw и Telegram.
- Docker, развёртывание и TASK-004.

- [x] Каждое выводимое нормализованное значение трассируется до исходного значения и версии правила.
- [x] Отсутствие, неподдерживаемое, невалидное, ошибка записи, несовпадение и пустой успех различаются.
- [x] Контракты источника, нормализации, коллекции, поиска и представления имеют малые тестируемые входы и выходы.
- [x] Зависимости направлены к предметным типам; Pydantic, JSON и CLI не входят в ядро.
