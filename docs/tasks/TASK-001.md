# TASK-001 — первоначальный фундамент проекта

- Статус: завершено
- Рабочая ветка: `task/001-project-foundation`
- Целевая ветка: `main`

## Цель

Создать Git-репозиторий и документальный фундамент, по которому независимая будущая сессия сможет понять назначение, архитектурные ограничения, порядок работы и текущее состояние проекта без доступа к предыдущим чатам.

## Включённый объём

- Инициализация Git с основной веткой `main`.
- Работа в ветке `task/001-project-foundation` и её интеграция в `main`.
- Создание корневой проектной документации и каталогов `docs/tasks/` и `docs/decisions/`.
- Фиксация продуктовых, доказательных и архитектурных принципов.
- Описание небольших задач, текущего состояния и правил будущих сессий.
- Минимальный `.gitignore` для системных и редакторских файлов.
- Проверка существования, форматирования и согласованности документов.

## Исключённый объём

- Выбор окончательного технологического стека.
- Любой программный код и зависимости.
- База данных, API, пользовательский интерфейс и Docker.
- Парсеры конкретных площадок и сетевой сбор данных.
- ИИ и выбор его провайдера или модели.
- Интеграции с OpenClaw и Telegram.
- Динамический загрузчик внешних плагинов.
- Удалённый репозиторий и публикация на GitHub.
